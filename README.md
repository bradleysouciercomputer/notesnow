# NotesNow

A simple notes website built with Google's official Material Web components.

## What it does

- Create notes with a title and written content
- Open an existing note to edit it
- Automatically save notes in the current browser using local storage

## GitHub Pages

In the repository, open **Settings → Pages** and choose:

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/(root)`

The website will be available at:

https://bradleysouciercomputer.github.io/notesnow/

## Storage

Notes stay in this browser on this device. They are not uploaded to a server and do not automatically sync between devices. Clearing browser site data can remove locally saved notes.

The site loads `@material/web` and Google Fonts from their CDNs, so an internet connection is needed for the Material components and fonts.
